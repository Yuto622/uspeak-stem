# U-Speak STEM

**本物の物理と本物の宇宙のデータで、歩いて入れる科学の世界。**
子どもは島を歩き、予想して、実験して、測って、**英語で**説明する。
結果はサーバーが同じ物理でもう一度計算して確かめる。

**見た目は U-Speak Web と同じ。** 島の部品（`client/island-kit.js`）は英語版からそのまま持ってきたもので、
段々のボクセルの島・桟橋・名前の札がかかった家・街灯・クリーム色の HUD・左のノート・右の地図とレール、
すべて英語版の子どもが知っている形で出る。

**島には地形の個性がある。** COSMOS は電波望遠鏡の峰、LAB は温室と煙突のキャンパス、ATOMS は紫の結晶の採石場、
FORCE は大すべり台と観覧車の遊び場、LIFE は小川と風車、BODY はスタンドと電光掲示板の競技場、EARTH は煙を上げる火山、
MAKER は工場とクレーン、DATA はサーバーラックの並ぶ広場。駅は島ごとに4〜8つ（`client/islands.json`、建て方は `islands-build.js`）。

**世界には時計がある**（`client/world-clock.js`）。英語版と同じ 705 秒の1日（昼 300・夕 120・夜 240・朝 45）。
壁時計の純粋関数なので、どのクラスのどの子も同じ空を見る。夜は月が出て、街灯がつき、天文台が本領を出す。

## 9つの島と 58 の実験 — 日本の理科教科書を鏡にして

小3〜中3の「理科」の単元を、学習指導要領と主要教科書（東京書籍・大日本図書・啓林館）の順にそのまま島に写した。
単元 → 島 → 実験の対応表と、化学の全単元の一覧は [docs/uspeak-stem-curriculum.md](docs/uspeak-stem-curriculum.md)。
**化学は小3「物と重さ」から中3「中和・電池」まで15実験**で、教科書の数値（溶解度表、Cu:O＝4:1、H2:O2＝2:1、78°C/100°C…）をそのまま使う。

## 動かす

```sh
cd server && npm install
npm start                    # http://localhost:2568
TEACHER_KEY=xxxx npm start   # 先生キーを決めると、先生コンソールが開く
```

ブラウザで開き、名前とクラスのコードを入れる。同じコードの子が同じ島に入る。
右の「✈ Islands」か ホットバーの 3 で、7つの島を行き来する。右のレールの時計が、いまの空（昼・夕・夜・朝）と残り時間。

## しくみ（ここだけ守ること）

1. **`shared/` はブラウザとサーバーが同じファイルを読む。** 物理と化学（`shared/sim`）と実験の定義（`shared/experiments`）。
   純粋関数だけ。時計・乱数・DOM を読む関数はここに置かない。乱数は `rng(seed)` から。
2. **結果は、予想を送ったあとにしか来ない。** `lab:start` → `lab:ready`（結果なし）→ `lab:predict` → `lab:result`。
   予想は結果より先に保存され、あとから変えられない。これが「シミュレーション」を「実験」にする1つの規則。
3. **測ったものはサーバーが再計算して比べる。** ページが報告した値がサーバーの値と合わなければ、点にならない。
4. **深さ（explore / investigate / engineer）は先生が決める。** ページが送っても無視される。
5. **英語の説明は aims（キーワードの組）で判定する。** 英語版の台本モードと同じ作り。あとで AI に置き換えられる。
6. **画面は英語が主、「あ」で日本語。** 文字は `<b class="en">` / `<i class="ja">` で両方書く。学習の中身は訳さない。
7. **島は `island-kit.js` で建てる。** 英語版の `createIsland({scene, build})` そのもの。建物の名前は `{en, ja}` で渡す。

## 足すとき

- **実験を足す**：`shared/experiments/*.json` を書き、`index.js` に import を1行。壊れていれば起動時に落ちる。画面の言葉（測定項目のラベル・予想の問い・選択肢の言葉）は JSON の `ui` に書く。
- **物理を足す**：`shared/sim/` にモジュールを足し、`run.js` の `switch` に1つ。
- **島を足す**：`client/islands.json` に1つ（`terrain` と駅の `kind`）、`client/islands-build.js` の `TERRAIN` に1つ、駅の `kind` が新しければ `PROPS` に1つ。`REGIONS`（`shared/experiments/index.js`）に1行。
- **3D の舞台を足す**：`client/stage-more.js` に builder を1つ（`sim` の名前で）。
