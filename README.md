# U-Speak STEM

**本物の物理と本物の宇宙のデータで、歩いて入れる科学の世界。**
子どもは島を歩き、予想して、実験して、測って、**英語で**説明する。
結果はサーバーが同じ物理でもう一度計算して確かめる。

段0（6週）の最初の形：**COSMOS（宇宙の島）**と実験3本。

| 場所 | 実験 | 使う物理 |
|---|---|---|
| つきの おか | 月の満ち欠け（小4・小6） | 本物の月齢。太陽・地球・月の角度 → 見える形 |
| うちあげだい | 軌道の発射台（中3） | ニュートン重力・ベロシティ・ベルレ積分。ISS の周期 92分、静止軌道 42,164 km が出る |
| てんもんだい | 系外惑星ハンター | トランジット（惑星が星の前を通って暗くなる）。TRAPPIST-1 b など4つの本物の惑星のパラメーター |

設計書は `docs/uspeak-stem-design.md`、市場は `docs/uspeak-stem-market.md`。

## 動かす

```sh
cd server && npm install
npm start                # http://localhost:2568
TEACHER_KEY=xxxx npm start   # 先生キーを決めると、先生コンソールが開く
```

ブラウザで開き、名前とクラスのコードを入れる。同じコードの子が同じ島に入る。

## しくみ（ここだけ守ること）

1. **`shared/` はブラウザとサーバーが同じファイルを読む。** 物理（`shared/sim`）と実験の定義（`shared/experiments`）。
   純粋関数だけ。時計・乱数・DOM を読む関数はここに置かない。乱数は `rng(seed)` から。
2. **結果は、予想を送ったあとにしか来ない。** `lab:start` → `lab:ready`（結果なし）→ `lab:predict` → `lab:result`。
   予想は結果より先に保存され、あとから変えられない。これが「シミュレーション」を「実験」にする1つの規則。
3. **測ったものはサーバーが再計算して比べる。** ページが報告した値がサーバーの値と合わなければ、点にならない。
4. **深さ（explore / investigate / engineer）は先生が決める。** ページが送っても無視される。
5. **英語の説明は aims（キーワードの組）で判定する。** 英語版の台本モードと同じ作り。あとで AI に置き換えられる。
6. **画面は英語が主、「あ」で日本語。** 文字は `<b class="en">` / `<i class="ja">` で両方書く。学習の中身は訳さない。

## 検査

```sh
cd server
npm test            # 物理（教科書の値と一致）・判定・部屋（実ソケットで順番と先生の権限）
npm run test:e2e    # 実ブラウザ：2人で入り、先生が深さを変え、予想→実行→測定→説明→クラスのデータ→言語切り替え
```

## 足すとき

- **実験を足す**：`shared/experiments/*.json` を書き、`index.js` に import を1行。壊れていれば起動時に落ちる。
- **物理を足す**：`shared/sim/` にモジュールを足し、`run.js` の `switch` に1つ。
- **島に建物を足す**：`client/island.js` の `STATIONS` に1行。

## データのライセンス

いま使っているのは、自分で計算した物理と、公開されている惑星のパラメーターだけ。
画像・星表を足すときは `docs/uspeak-stem-design.md` §11 の表に従う（NASA・ESA/Webb・PhET・SDSS は表記を守れば可。Gaia は許諾が要る）。
